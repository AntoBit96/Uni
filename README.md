# 🎓 University Archive & Coursework

Raccolta di presentazioni, relazioni di laboratorio, elaborati e materiale didattico realizzati durante il mio percorso universitario.

---

## 📌 Panoramica

Questo repository funge da archivio personale per tracciare e conservare i progetti, le presentazioni (slide) e i documenti di approfondimento sviluppati per vari corsi accademici.

L'obiettivo principale è:
- Mantenere uno storico consultabile del lavoro svolto.
- Condividere risorse utili (slide, report, appunti strutturati) con altri studenti o colleghi.
- Documentare l'evoluzione di competenze teoriche e pratiche nel tempo.

---

## 🗂️ Struttura della Repository

I contenuti sono organizzati per anno accademico / corso di laurea e suddivisi per singola materia:

```text
.
├── Laurea-Triennale/           # (oppure Anno-1, Anno-2, ecc.)
│   ├── [Nome-Materia-1]/
│   │   ├── docs/               # Relazioni, tesine, report in PDF/DOCX
│   │   ├── slides/             # Presentazioni (PDF, PPTX, Keynote)
│   │   └── src/                # Eventuale codice sorgente o file sorgente LaTeX
│   └── [Nome-Materia-2]/
│       └── ...
├── Laurea-Magistrale/
│   └── ...
└── README.md
```
